# 求职填表快捷键工具包

把填表时要反复输入的内容（姓名、邮箱、学历、实习经历、开放题答案……）做成 **macOS 系统级文本替换**。
以后在任何网页表单里，打一个缩写再敲空格，整段内容自动展开。

不用装任何软件，不用联网，不依赖 AI —— 装一次，一直能用。

> 适用系统：**macOS**。纯 Python 3 标准库写的，macOS 自带的 python3 就够，没有第三方依赖。

---

## 一、取得工具包

**方式 A：直接下载（推荐给不用 git 的同学）**

点本页右上角绿色的 **`Code`** 按钮 → **`Download ZIP`**，解压即可。

或者直接下载仓库里已经打包好的 **[`求职填表快捷键工具包.zip`](求职填表快捷键工具包.zip)**。

**方式 B：git clone**

```bash
git clone https://github.com/Quentin040507/job-apply-shortcuts.git
cd job-apply-shortcuts
```

两种方式拿到的东西一样。解压 / clone 完，目录结构是：

```
job-apply-shortcuts/
├── README.md                    ← 你正在看的这份说明
├── kit/
│   ├── jobkit.py                ← 核心程序（单文件，无依赖）
│   └── ① 开始使用.command        ← 双击这个
└── data/
    └── profile.json             ← 你的资料（全是示例内容，要改成自己的）
```

## 二、三步开始

1. **解压**：把整个文件夹解压出来（放在桌面、文稿里都行，之后可以随便挪）。
2. **双击 `kit/① 开始使用.command`**。
   - 会弹出一个小黑窗口，同时浏览器打开编辑页面。
   - **不要关那个黑窗口**，它就是编辑器本体；用完了再关。
3. **在页面里把示例内容改成你自己的**，然后点右上角的 **「安装到系统」**。

装完，桌面会自动生成一份《我的求职快捷键速查.html》——可以搜索、点一下复制、也能直接打印。

> 想先试试效果？什么都不用改，直接点「安装到系统」，然后打开备忘录打 `；；uni` 再敲空格。

## 三、首次打开被 macOS 拦住了？

从网上下载的文件，macOS 会拦一次，这是正常的。

**做法**：在 `① 开始使用.command` 上 **右键 → 打开 → 再点「打开」**。只需要做这一次。

如果右键也没有「打开」选项，或者提示更复杂，打开「终端」，把下面这行粘进去回车（**把路径换成你实际的文件夹路径**：在 Finder 里把文件夹拖进终端窗口就会自动填好）：

```bash
xattr -dr com.apple.quarantine "/你的/路径/job-apply-shortcuts"
```

然后再双击就可以了。

## 四、日常怎么用

在任意输入框里打 **缩写 + 空格**：

| 你打的 | 展开成 |
|---|---|
| `；；email` + 空格 | `liming@example.com` |
| `；；uni` + 空格 | `Example University` |
| `；；unicn` + 空格 | `示例大学` |
| `；；exp` + 空格 | 整段实习经历（含项目符号） |

中文内容统一在缩写后面加 `cn`，例如 `；；unicn`、`；；namecn`。
缩写表在桌面的速查表里，也可以点页面右上角的搜索框查。

### 三个必须知道的坑

1. **打完缩写一定要再敲空格或回车**，不然不会展开。这是最常见的原因。
2. **半角 `;;` 和全角 `；；` 都注册了**，中文输入法下打出来是全角也没关系。
3. **终端、密码框、少数富文本编辑器里系统不管**，这些地方请打开速查表点一下复制。

### 没反应时的排查顺序

1. 缩写后面敲空格了吗？
2. 当前是不是在终端 / 密码框里？（换个地方试试）
3. 打开「系统设置 → 键盘 → 文本替换」，看条目在不在。
   - 在 → 说明是触发方式问题，回看上面三条。
   - 不在 → 回编辑页面，再点一次「安装到系统」。

## 五、改内容 / 加自己的条目

再双击 `kit/① 开始使用.command`（已经在跑就直接打开页面），改完点「安装到系统」。

- **改文字**：直接在框里改，点安装即可。
- **加一条**：点分组里的「＋ 在这个分组里加一条」，填缩写和名字。
- **加一个分组**：点顶部「＋ 新增分组」。
- **改缩写**：每个条目左边的小输入框就是缩写。**只能用字母和数字**——中文输入法下的连字符 `-` 会变成全角的 `－`，带连字符的缩写永远触发不了。
- **只要英文**：把中文框留空，这条就只生成英文缩写。
- **删掉某条不需要的**：清空内容后点安装，系统里对应的条目会被自动清理。

改动只影响这套工具写进去的条目；**你自己在系统设置里加的其他文本替换不会被碰**。

## 六、把它发给朋友

整个文件夹就是完整的工具，发给别人照样能用。两条注意事项：

1. 发之前，先把 `data/profile.json` 换成你自己的内容（或者直接删掉重置成示例）—— 里面是你的真实资料。
   - 带自己的资料发出去：朋友解压后直接就是你的版本。
   - 想给朋友一个干净版本：删掉 `data/profile.json` 和 `data/state.json`，重新双击一次就会回到示例内容。
2. 把文件夹压缩成 `.zip` 再发（微信传文件夹容易丢文件）。对方解压后需要做一次「右键 → 打开」。

## 七、卸载

- **只清掉快捷键**：编辑页面里点「卸载」，或者在终端里运行：
  ```bash
  python3 kit/jobkit.py --uninstall
  ```
- **彻底不要了**：先卸载，再把整个文件夹删掉，最后删掉桌面那份速查表。

卸载只移除这套工具写入过的条目（记录在 `data/state.json` 里），其它文本替换不受影响。

## 八、常见问题

**Q：Windows / 手机能用吗？**
A：这套靠 macOS 的文本替换，Windows 用不了。但 `data/profile.json` 里存的是纯文本资料，速查表 HTML 两边都能打开当「点一下复制」的答案库用。

**Q：能自动填表吗（真的点一下把整张表填完）？**
A：不能。浏览器出于安全限制，网页无法跨站自动填表。这套解决的是「同一段内容要打几十遍」的痛点——写求职信、开放题、表单备注框时，一次展开一整段。

**Q：会不会把我系统里别的东西搞坏？**
A：不会。程序只读改写「文本替换」这一个设置项，其它系统设置键完全不碰。写入前会先把你原有的条目读出来一起写回。

**Q：为什么我的系统设置里，文本替换被同步到 iPhone 了？**
A：这是 iCloud 的正常行为，不算坏事。但请注意 iPhone 上展开的是同一份内容。

**Q：编辑页面关了之后，快捷键还有效吗？**
A：有效。内容已经写进系统了，编辑页面只是用来改内容的。

**Q：装了之后突然不生效了？**
A：macOS 偶尔会把「文本替换」回滚成旧值。重新双击一次 `① 开始使用.command`，点「安装到系统」就会恢复。

## 九、技术说明（给想折腾的人）

- 纯 Python 3 标准库，**无第三方依赖**，macOS 自带的 python3 就够。
- 路径全部相对自身解析，整个文件夹可以任意移动 / 改名 / 换电脑。
- 写入方式：只导入 `NSGlobalDomain` 下 `NSUserDictionaryReplacementItems` 这一个键的片段 plist，不动同域其它键。
- 状态记录在 `data/state.json`（记录了本工具写过的缩写），更新与卸载都以它为准。
- 只处理你自己写的内容，不联网、不上传任何数据。

命令行备用入口：

```bash
python3 kit/jobkit.py --serve       # 打开编辑页面（等同双击启动器）
python3 kit/jobkit.py --install     # 按 profile.json 直接安装/更新
python3 kit/jobkit.py --status      # 查看安装状态
python3 kit/jobkit.py --uninstall   # 卸载
```
